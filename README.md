# omp-ui-themes

The official themes for [omp-ui](https://github.com/LankfordAI/omp-ui). Current omp-ui lists this repository under Settings → Appearance → Show without adding it; omp-ui 0.36.x users add `LankfordAI/omp-ui-themes` under Theme repositories.

- `themes/` holds one theme file (made with **Export**) and one details file (tags, description, author) per theme.
- `omp-ui-themes.json` (v1) and `omp-ui-themes.v2.json` are generated by the index workflow after each merge. Do not edit them.
- `tags.json` is the tag vocabulary; `featured.json` names the themes that lead the indexes.

To contribute a theme, read [CONTRIBUTING.md](CONTRIBUTING.md). Publishing your own theme repository: see [Publishing a theme repository](https://github.com/LankfordAI/omp-ui/blob/main/docs/settings.md#publishing-a-theme-repository).
