# omp-ui-themes

Themes for [omp-ui](https://github.com/LankfordAI/omp-ui). Add this repository under Settings → Appearance → Theme repositories as `LankfordAI/omp-ui-themes`.

`omp-ui-themes.json` is the theme index; each theme file is an omp-ui theme file produced by **Export**. See [Publishing a theme repository](https://github.com/LankfordAI/omp-ui/blob/main/docs/settings.md#publishing-a-theme-repository).
